# Montering, sæsondrift og opbevaring

## Før indkøb

- [ ] Mål facadens tagrende, carportforkant og den nødvendige kabellængde.
- [ ] Undersøg sikkert arbejdsniveau: stige/platform eller faglig hjælp.
- [ ] Gennemgå begge eksisterende strømudtag og RCD-beskyttelse.
- [ ] Undersøg, om egnede udendørs Zigbee-enheder kan nås fra HA.
- [ ] Vælg **ens varmhvidt** lys, afklar IP-klassifikation og strømforsyningskrav.
- [ ] Lav simpel placeringstegning af de **to** 2026-zoner.

## Test og opsætning

- [ ] Pak alle kæder ud, læg dem på jorden og test hele længden.
- [ ] Bekræft ens farvetone og eventuelle fabriksindstillinger efter strømafbrydelse.
- [ ] Montér aftagelige beslag på tilladt og sikker måde.
- [ ] Monter facetens istapper og derefter carportens forkant/guirlander.
- [ ] Før ledninger langs beskyttet rute uden klem-/snublefare.
- [ ] Placér transformere og stik beskyttet og i henhold til producentens anvisninger.
- [ ] Par og navngiv smart-stik i HA.
- [ ] Afprøv automationer og registrér fejl i Issues.
- [ ] Kontrollér udtrykket i mørke fra vejen uden at blænde trafikken.

## Nedtagning

- [ ] Sluk og afbryd spænding inden håndtering.
- [ ] Undersøg alle kæder, stik, kabler og clips for skader og fugt.
- [ ] Mærk udstyret `A facade` eller `B carport`.
- [ ] Opbevar tørt og uden mekanisk pres på LED-kablerne.
- [ ] Registrér faktisk forbrug, tidsforbrug og erfaringer.

## Sæsonreview

Spørg: Ser de to zoner balancerede ud? Var montering realistisk? Fungerede strøm og HA stabilt? Skal næste års levende træer placeres anderledes end først tænkt? Opdatér [beslutninger](beslutninger.md) og relevante Issues.
