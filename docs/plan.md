# Flerårig projektplan

## Principper

- Først arkitekturen, dernæst haven og til sidst detaljerne.
- Ét ensartet varmt hvidt udtryk uden røde/grønne RGB-effekter.
- Kun aftagelige og sikre installationer, ikke montering på selve tagfladen.
- Standard-lyskæder og central HA-styring er førstevalg; intelligent adresserbar LED er ikke nødvendigt.
- Hver ny etape skal kunne styres uafhængigt og fungere sammen med tidligere års indkøb.
- Ingen køb mere end én sæson frem uden en konkret grund.

## 2026: Facade og carport

**Mål:** Huset skal fremstå sammenhængende og flot med blot to lyszoner.

**Zone A, facade:** Varmhvid istaplyskæde langs den eksisterende tagrende på den lange facade. Forventet behov cirka 15-18 meter, **skal måles**. Strøm fra eksisterende udtag under tagrenden, hvis kontrollen viser, at det er egnet.

**Zone B, carport/indgang:** Varmhvid lyskæde på carportens **vandrette forkant**, granguirlander med varm hvid belysning omkring åbningen samt enkel indgangsdekoration som del af samme zone. Strøm fra eksisterende udtag ved hoveddøren, hvis egnet.

**Ikke 2026:** ingen lys i hækken, ingen små juletræer, ingen kunstige lystræer, ingen stjerner i vinduerne, ingen lys langs fliser eller fortov, ingen lys på tagryg, gavltop eller tagflade, ingen nye bede eller buske.

**Godkendelseskriterier:**
- [ ] Faktiske mål og monteringsmetode dokumenteret.
- [ ] Sikker strømføring og beskyttede forbindelser afprøvet.
- [ ] Kun de to aftalte zoner har udendørs julelys.
- [ ] Begge zoner kan styres særskilt i HA.
- [ ] Automatisk tænding ved mørke og slukning om aftenen fungerer.
- [ ] Kabler/fastgørelser kan demonteres og opbevares mærket.

## 2027: Levende juletræer og eventuelt hæk

**Vigtig ændring:** Brug **rigtige, levende små nåletræer, der plantes permanent** og vokser år for år. Ikke kunstige lystræer. Træart, placering, forventet sluthøjde og afstande til hus, vej, rør og brønddæksel afklares før plantning. Juletræslys skal kunne forlænges, efterhånden som træerne vokser.

- Vælg placeringer på plænen og antal, foreløbigt op til tre.
- Undersøg træarter og jord, voksenstørrelse, pleje og vintervanding.
- Planlæg 24/31V lavvoltlys og føring, der kan fjernes ved slåning.
- Overvej hæklys som separat zone, hvis budget og visuelt udtryk passer.
- Opdatér årsbudget ud fra aktuelle priser før køb.

## 2028: Vinduer og afgrænsede detaljer

- 2-3 varme hvide stjerner placeret **inde** i vinduerne.
- Kun hvis det ønskes: flytbare lavvoltlamper ved **egen indkørsel/flisekant**. Ikke på offentligt fortov. Placeringen er **ikke besluttet**.
- Udvid HA og gennemgå strømfordeling.

## 2029: Finish og stabilitet

- Reparer eller udskift svage led, forbedr kabelskjul og styring.
- Tilføj kun dekorationer, der forbedrer helheden, ikke nødvendigvis mere lys.
- Gennemgå budget, energiforbrug og sæsonopbevaring.

## Årligt kontrolpunkt
