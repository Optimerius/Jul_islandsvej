For hvert køb registreres:
- Model og fabrikant, så vi kan supplere med samme farvetone og stiksystem.
- Detaljer om IP-rating, transformer og stiktype.
- Garanti/kvittering opbevaret **privat** (ikke personlige dokumenter her).
- Mål, installationstid og kendte fejl.

Opmåling og valg af produkter behandles først i GitHub Issues.
